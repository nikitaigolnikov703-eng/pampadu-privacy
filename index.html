Политика обработки персональных данных

Редакция от 21 ноября 2026 года

1. Общие положения

Настоящая Политика определяет порядок обработки персональных данных пользователей Telegram-бота «Навигатор подработки | Россия» (@PodrabotkaNavigatorBot, далее — Бот). Бот является независимым сервисом подбора партнёрских предложений и не является официальным сервисом Яндекса, Pampadu или работодателей.

Оператор персональных данных — физическое лицо: [ФАМИЛИЯ ИМЯ ОТЧЕСТВО (ПРИ НАЛИЧИИ)]. Контакт для обращений по вопросам персональных данных: [КОНТАКТНЫЙ EMAIL ОПЕРАТОРА].

Политика действует в отношении обработки данных, осуществляемой Оператором при взаимодействии с Ботом. Вопросы обработки данных самой платформой Telegram регулируются её собственными документами.

2. Для чего обрабатываются данные

Оператор использует минимально необходимые сведения для ответа на запрос пользователя, определения выбранного города, подбора доступных вакансий и предоставления ссылок на предложения партнёров.

Также данные могут использоваться для учёта источника обращения, количества выданных ссылок, технической защиты Бота, предотвращения повторной обработки одного события и исполнения запросов пользователя о прекращении обработки.

Рекламные рассылки и регулярные уведомления не подключаются автоматически. Для них требуется самостоятельное правовое основание и, в предусмотренных законом случаях, отдельное предварительное согласие пользователя.

3. Какие данные обрабатываются

При работе Бота могут обрабатываться: числовой идентификатор чата Telegram, выбранный пользователем город, источник перехода/обращения, факт согласия на обработку данных, время создания и обновления карточки, состояние диалога, статистика выдачи партнёрских ссылок и технические идентификаторы событий Telegram.

Содержание введённых сообщений используется для обработки команды или определения города. В текущей версии Бота не предполагается целенаправленный сбор паспортных данных, банковских реквизитов, сведений о здоровье и иных специальных категорий персональных данных. Не отправляйте такие сведения в чат.

Если пользователь переходит по партнёрской ссылке и заполняет анкету на стороннем сайте, дальнейший сбор данных на таком сайте осуществляется по правилам соответствующего владельца сайта. Бот не требует у пользователя заполнять анкету непосредственно в Telegram.

4. Основания и порядок обработки

Основанием обработки сведений, необходимых для персонального подбора, является добровольное, конкретное, информированное и сознательное согласие пользователя, получаемое отдельно от настоящей Политики в интерфейсе Бота. В предусмотренных законом случаях обработка может осуществляться на иных основаниях, установленных статьёй 6 Федерального закона № 152-ФЗ.

После нажатия /start Бот предоставляет информацию об обработке данных и предлагает отдельное действие для согласия. При отказе карточка подбора не создаётся. При этом сама платформа Telegram передаёт Боту техническую информацию, необходимую для обработки входящего сообщения.

Обработка включает получение, запись, систематизацию, хранение, использование, изменение, извлечение и удаление сведений в объёме, необходимом для указанных целей. Решения о приёме на работу Бот не принимает.

5. Хранение и безопасность

Карточки подбора сохраняются в базе YDB в инфраструктуре Yandex Cloud, для которой выбран российский регион размещения. Доступ к базе ограничивается назначенными техническими правами; для управления системой используются средства аутентификации и проверки служебных запросов.

Данные должны храниться не дольше, чем необходимо для целей обработки, если иной срок не установлен законом. При достижении цели либо при законном отзыве согласия Оператор прекращает соответствующую обработку и организует удаление данных в сроки, предусмотренные законодательством.

Команда /delete удаляет основную карточку подбора из базы приложения. Она сама по себе не удаляет переписку из Telegram и не гарантирует автоматического удаления технических записей, которые могут обрабатываться отдельно. Для запроса о полном объёме данных используйте контакт Оператора, указанный в разделе 1.

6. Кому могут быть доступны данные

Для работы Бота используются Telegram как платформа обмена сообщениями и Yandex Cloud как облачная инфраструктура хранения и исполнения кода. Обработка этими поставщиками осуществляется в пределах их функций, применимых договоров и политик.

При переходе по партнёрской ссылке пользователь покидает Бота и взаимодействует со сторонним ресурсом. Сайты Pampadu, Яндекса и работодателей самостоятельно определяют порядок обработки данных, полученных на их страницах.

При подключении интеграции со статистикой партнёрской программы Оператор может обрабатывать технические идентификаторы и статусы целевых действий. Перед включением такой интеграции перечень передаваемых и получаемых сведений подлежит дополнительной проверке.

7. Трансграничная передача

Платформа Telegram и хостинг публичной страницы GitHub Pages являются самостоятельными интернет-сервисами; при взаимодействии с ними технические данные могут обрабатываться с участием зарубежной инфраструктуры. Оператор оценивает применимость требований статьи 12 Федерального закона № 152-ФЗ к конкретным потокам данных до запуска соответствующей обработки.

Страница политики на GitHub Pages не содержит формы подачи заявки и не предназначена для сбора данных кандидатов. Введение новых внешних сервисов и передача им данных требуют предварительной оценки и при необходимости обновления настоящей Политики.

8. Права пользователя

Пользователь вправе получать сведения об обработке своих персональных данных, требовать их уточнения, блокирования или удаления при наличии законных оснований, отзывать согласие и обращаться с жалобой в уполномоченный орган или суд.

Для удаления основной карточки подбора используйте команду /delete. Для отзыва согласия, получения информации о данных или других запросов обращайтесь по адресу [КОНТАКТНЫЙ EMAIL ОПЕРАТОРА]. В запросе укажите способ связи и сведения, позволяющие подтвердить, что обращение касается именно ваших данных, без отправки лишних документов.

Команда /stop предназначена для отключения возможных уведомлений и не равнозначна удалению всех данных.

9. Изменения Политики

При изменении работы Бота, состава данных, подрядчиков или правовых требований Оператор актуализирует Политику. Действующая редакция размещается по постоянному адресу этой страницы.
